# Daily Tools

Static, GitHub Pages/hosting-ready website containing calculators, guides and legal pages.

## Before publishing

1. Replace `YOUR-DOMAIN.com` in `robots.txt` and `sitemap.xml`.
2. Replace `contact@yourdomain.com` in `contact.html` with your real email.
3. Add your real AdSense meta tag only after Google provides it.
4. After AdSense approval, replace the placeholder `ads.txt` content with the exact line from your AdSense account.
5. Review all content and add your own original articles before applying for AdSense.
6. Add a favicon and your own branding if desired.

This project is intentionally static and has no backend or user database.
